## 🚀 Sobre mim

Atuo criando soluções que conectam **software, automação, infraestrutura e operação comercial**. Meu foco é transformar problemas reais de empresas em sistemas práticos, escaláveis e integrados.

Atualmente estudo e desenvolvo projetos envolvendo:

- plataformas SaaS multi-tenant;
- CRMs com atendimento integrado;
- automações para WhatsApp, marketplaces e ecommerce;
- bots, fluxos com n8n e integrações externas;
- infraestrutura com Docker, Portainer, Nginx Proxy Manager e servidores Linux;
- uso de IA em atendimento, produtividade, análise e sistemas internos;
- produtos digitais para empresas locais e operações comerciais.
